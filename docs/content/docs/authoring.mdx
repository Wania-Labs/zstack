This page is for people who maintain zstack itself. Consumer clones never receive it.

## Docs isolation

`docs/` is a **standalone** pnpm project:

- Own `package.json` and lockfile
- **Not** in the product `pnpm-workspace.yaml`
- **Not** in Alchemy / Turborepo product tasks
- **Not** copied by `create-zstack`

```bash
cd docs && pnpm install && pnpm dev    # :4000
```

## CI

| Workflow                     | Scope                                                                                                                |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `.github/workflows/ci.yml`   | Product monorepo — ignores `docs/**`                                                                                 |
| `.github/workflows/docs.yml` | Docs only — install, `check:docs`, typecheck, lint, format, Worker build. Deploy is Workers Builds, not this job |

Never fold docs typecheck or install into the product CI job.

When you add or rename a teaching page, update `REQUIRED` in `docs/scripts/check-docs-completeness.mjs` or CI fails.

## Template wiring policy

1. Do not bind the author's real SaaS accounts into the template.
2. Scaffold ready-to-wire adapters so a clone turns a capability on with config and secrets.
3. Core local paths use Compose, console, and empty DSN.
4. Optional vendors stay `absent` or `configured` until a clone flips them.

Full detail lives in `AUTHORING.md` at the repo root (also stripped from clones).
