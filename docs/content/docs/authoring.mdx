This page is for people who maintain zstack itself. Consumer clones never receive it.

## Docs isolation

`docs/` is a **standalone** pnpm project:

- Own `package.json` and lockfile
- **Not** in the product `pnpm-workspace.yaml`
- **Not** in Alchemy / Turborepo product tasks
- **Not** copied by `create-zstack`

```bash
cd docs && pnpm install && pnpm dev    # :4000
```

Production is a Cloudflare Worker named `zstack` (must match `docs/wrangler.jsonc`). It uses the official TanStack Start Cloudflare path: `@cloudflare/vite-plugin` with `viteEnvironment.name = "ssr"`, plus `main: "@tanstack/react-start/server-entry"`. `wrangler` is a **direct** docs `devDependency`. pnpm does not hoist the copy nested under the Vite plugin, and Workers Builds needs `wrangler` on PATH for `npx wrangler deploy`.

This Worker is authoring-only. Product clones deploy with Alchemy. Do not add `@cloudflare/vite-plugin` to `apps/web` or `apps/admin`.

## CI and deploy

| Workflow                     | Scope                                                                                                 |
| ---------------------------- | ----------------------------------------------------------------------------------------------------- |
| `.github/workflows/ci.yml`   | Product monorepo. Ignores `docs/**`                                                                   |
| `.github/workflows/docs.yml` | Docs only: install, `check:docs`, typecheck, lint, format, Worker build. No deploy job, no CF secrets |

Never fold docs typecheck or install into the product CI job.

Production deploy is **Workers Builds** in the Cloudflare dashboard, not GitHub Actions:

| Setting           | Value                                  |
| ----------------- | -------------------------------------- |
| Root directory    | `docs`                                 |
| Build command     | `pnpm build`                           |
| Deploy command    | `npx wrangler deploy`                  |
| Production branch | `main`                                 |
| Worker name       | `zstack` (must match `wrangler.jsonc`) |

`create-zstack` strips `.github/workflows/docs.yml` from clones.

When you add or rename a teaching page, update `REQUIRED` in `docs/scripts/check-docs-completeness.mjs` or CI fails.

## Template wiring policy

1. Do not bind the author's real SaaS accounts into the template.
2. Scaffold ready-to-wire adapters so a clone turns a capability on with config and secrets.
3. Core local paths use Compose, console, and empty DSN.
4. Optional vendors stay `absent` or `configured` until a clone flips them.

Full detail lives in `AUTHORING.md` at the repo root (also stripped from clones).
