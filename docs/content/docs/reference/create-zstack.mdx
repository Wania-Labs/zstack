Authoring-only CLI: citty + giget + nypm. Not present in consumer clones.

## Commands

```bash
pnpm create-zstack my-app
pnpm create-zstack my-app --template file:$(pwd) --force
pnpm create-zstack my-app --no-install
```

Environment override: `ZSTACK_TEMPLATE`. Default remote: `gh:Wania-Labs/zstack`.

## Ignored from clones

```text
tech-stack-architecture-guide/**
AUTHORING.md
.cursor/**
create-zstack/**
docs/**
agent-transcripts/**
.audit/**
```

After download, `stripAuthoringManifest` also:

- drops the `create-zstack` workspace member from `pnpm-workspace.yaml`
- removes the root `create-zstack` script from `package.json`
- deletes `.github/workflows/docs.yml` (docs live only in the authoring tree)
- rewrites consumer README so it no longer points at authoring-only paths

Keep `create-zstack/src/cli.ts` (`CONSUMER_IGNORE`), `create-zstack/src/prepare-consumer.ts`, `AUTHORING.md`, and this page in sync when you add authoring-only paths.

## Local smoke

```bash
ZSTACK_TEMPLATE=file:$(pwd) pnpm create-zstack /tmp/zstack-smoke --force
```
