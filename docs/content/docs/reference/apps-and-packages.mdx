## Apps

| Path         | Package         | Role                                     |
| ------------ | --------------- | ---------------------------------------- |
| `apps/api`   | `@zstack/api`   | Hono Worker: auth, oRPC, Effect, Drizzle |
| `apps/web`   | `@zstack/web`   | Customer TanStack Start                  |
| `apps/admin` | `@zstack/admin` | Staff TanStack Start                     |

## Packages

| Path                         | Package                     | Role                             |
| ---------------------------- | --------------------------- | -------------------------------- |
| `packages/contracts`         | `@zstack/contracts`         | Zod + oRPC contracts             |
| `packages/auth-access`       | `@zstack/auth-access`       | Shared Better Auth admin role AC |
| `packages/email`             | `@zstack/email`             | React Email templates            |
| `packages/typescript-config` | `@zstack/typescript-config` | Shared TS config                 |

## Root toolchain

| Path                  | Role                                                                                    |
| --------------------- | --------------------------------------------------------------------------------------- |
| `pnpm-workspace.yaml` | Workspace members: `apps/*`, `packages/*`, `create-zstack` (`@wanialabs/create-zstack`) |
| `turbo.json`          | Product tasks (docs are not included)                                                   |
| `alchemy.run.ts`      | Alchemy stack entry                                                                     |
| `infra/`              | api / web / admin / database resources                                                  |
| `product.config.ts`   | Capability intent                                                                       |
| `AGENTS.md`           | Coding-agent playbook (ships to clones)                                                 |
| `.agent/playbooks/`   | Multi-step agent procedures                                                             |
| `.agent/skills/`      | Agent skills (Effect, …)                                                                |
| `compose.yaml`        | Local Postgres 18                                                                       |

## Authoring-only (stripped from clones)

`docs/`, `create-zstack/`, `tech-stack-architecture-guide/`, `AUTHORING.md`, `.cursor/`, `agent-transcripts/`, `.audit/`.

Optional Cursor/Claude/OpenCode packs are written by `create-zstack --agent-tools` after download (they are not copied from the authoring `.cursor/` tree). Use `--skills=copy|symlink|none` to install `.agent/skills` into tool skill dirs. See [Coding agents](/docs/guides/coding-agents).
