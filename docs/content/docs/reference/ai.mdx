Product code asks for **capability IDs** (`chat.fast`, `chat.smart`, `extract.structured`). Model strings live only in `apps/api/src/platform/ai/`.

## Defaults

- Empty `AI_GATEWAY_API_KEY` → deterministic **fake** models (no spend)
- Key bound → Vercel AI Gateway via `@ai-sdk/gateway`
- oRPC: `ai.capabilities` (public), `ai.complete` (signed-in)

## Policy table

Policies live in `apps/api/src/platform/ai/capabilities.ts`. Each entry sets `gatewayModelId`, `maxOutputTokens`, and `temperature` for one capability ID.

## File map

| Path                                       | Role                    |
| ------------------------------------------ | ----------------------- |
| `apps/api/src/platform/ai/capabilities.ts` | Capability → policy     |
| `apps/api/src/platform/ai/registry.ts`     | `resolveAiModel`        |
| `apps/api/src/platform/ai/ai-service.ts`   | `AiService` Effect port |
| `apps/api/src/platform/ai/fake-model.ts`   | Deterministic fake      |
| `packages/contracts/src/ai.ts`             | Client-safe schemas     |

## Evals

`vitest-evals` + `@vitest-evals/harness-ai-sdk` run in product CI with fake models. Live gateway evals are opt-in and never the default gate.
