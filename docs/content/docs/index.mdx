**zstack** is a cloneable Cloudflare-first TypeScript product starter for solo founders and small teams shipping AI-capable SaaS without locking domain code to vendor APIs.

You clone one repository with create-zstack. That repo **is** the product: customer web app, staff admin console, and one Effect-backed Hono Worker. Optional vendors stay quiet until you bind credentials. Day-to-day work runs on Compose Postgres and `alchemy:dev`, not a paid cloud account.

Unlike Next.js starters or thin Cloudflare demos, zstack gives you Workers with real product boundaries and agents that land productive day one.

## What you get

- `apps/web` — customer TanStack Start app with Better Auth
- `apps/admin` — staff console TanStack Start app with role access
- `apps/api` — Hono Worker with Effect, oRPC, Drizzle, workflows, queues
- `packages/contracts` — Zod + oRPC contracts safe to import from frontends
- `packages/email` — React Email templates with console/Bento transport
- Alchemy IaC for Cloudflare Workers, PlanetScale Postgres, Hyperdrive, secrets
- AI capability registry with AiService and gateway for fake/live model swap

## How swap works

zstack is not a plugin marketplace. Domain code depends on Effect **ports** such as `EmailService` and `AiService`. The Worker edge picks a concrete **Layer** from env and secrets. `product.config.ts` records structural intent (`absent` or `configured`). Empty credentials keep the console, fake, or off path active.

## Authoring vs consumer clones

This documentation site lives in the **authoring** repository only. `create-zstack` strips `docs/`, the architecture guide, the CLI itself, and `AUTHORING.md` from consumer clones. Clones keep the product monorepo. Humans (and agents) still learn from this site.
