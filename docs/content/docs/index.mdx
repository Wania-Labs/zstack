title: What is zstack

**zstack** is a cloneable TypeScript product starter for solo founders and small teams who want a Cloudflare-first SaaS monorepo without locking domain code to vendor APIs.

You clone one repository. That repo is one business product: a customer UI, a staff console, and a single Hono Worker backend. Optional vendors stay quiet until you bind credentials. Day-to-day work runs on Compose Postgres and `alchemy:dev`, not a paid cloud account.

## What you get

- `apps/web` — customer TanStack Start app
- `apps/admin` — staff TanStack Start console
- `apps/api` — Hono Worker with Effect, Better Auth, oRPC, and Drizzle
- `packages/contracts` — Zod + oRPC contracts shared with the frontends
- Alchemy as the sole deploy and provision owner for Cloudflare and PlanetScale

## How swap works

zstack is not a plugin marketplace. Domain code depends on Effect **ports** such as `EmailService` and `AiService`. The edge picks a concrete **Layer** from env and secrets. `product.config.ts` records structural intent (`absent` or `configured`). Empty credentials keep the console, fake, or off path.

## Authoring vs consumer clones

This documentation site lives in the **authoring** repository only. `create-zstack` strips `docs/`, the architecture guide, the CLI itself, and `AUTHORING.md` from consumer clones. Clones keep the product monorepo. Humans (and agents) still learn from this site.
