title: Getting started

You will scaffold a consumer product, start Compose Postgres, migrate, and open the customer app.

## Scaffold

```bash
npm create @wanialabs/zstack@latest my-product
pnpm create @wanialabs/zstack my-product
yarn create @wanialabs/zstack my-product
bunx @wanialabs/create-zstack my-product

# non-interactive + coding-agent packs (symlink skills into Cursor/Claude dirs):
pnpm create @wanialabs/zstack my-product --yes --agent-tools=cursor,claude --skills=symlink

# pick install tool explicitly (default with --yes is pnpm):
pnpm create @wanialabs/zstack my-product --yes --package-manager=npm
```

From a clone of this authoring repo you can point at the local tree (giget uses `git:`, not `file:`):

```bash
pnpm create-zstack my-product --template git:./ --yes
# or:
ZSTACK_TEMPLATE=git:$(pwd) pnpm create-zstack /tmp/zstack-smoke --force --yes
```

`@wanialabs/create-zstack` downloads the template with giget, strips authoring-only paths, optionally writes coding-agent packs (`--agent-tools` / `--mcp` / `--skills`), and installs with nypm. Default remote: `gh:Wania-Labs/zstack`. Requires Node.js `>=22.5`. The clone always includes `AGENTS.md`, `.agent/playbooks/`, and `.agent/skills/`. See [Coding agents](/docs/guides/coding-agents) (includes a paste-ready agent setup prompt).

## First run in the clone

```bash
cd my-product
cp apps/api/.dev.vars.example apps/api/.dev.vars
pnpm dev:services
pnpm db:migrate && pnpm db:seed
pnpm alchemy:dev
```

| Surface       | URL                   |
| ------------- | --------------------- |
| Customer app  | http://localhost:3000 |
| Staff console | http://localhost:3001 |
| API Worker    | http://localhost:8787 |

Sign up on the customer app (`/sign-up`), name a Team when prompted, then open the appshell under `/t/<slug>`. Members (`/t/<slug>/members`) is the example team feature to copy.

Promote yourself to staff with:

```bash
STAFF_EMAIL=you@example.com pnpm db:seed
```

Then open the staff console at http://localhost:3001/login. Use **Users** to promote more people after the first seed.

## Secrets for local smoke

Copy `apps/api/.dev.vars.example` to `apps/api/.dev.vars`. Keep `BETTER_AUTH_URL=http://localhost:3000`. Generate `BETTER_AUTH_SECRET` with `openssl rand -base64 32` when Alchemy needs it in the process env.

Optional vendors (Bento, Sentry, AI Gateway, Polar, PostHog) stay off until you set their env vars. See [Capabilities](/docs/concepts/capabilities).

## Prefer Alchemy for full stack

`pnpm alchemy:dev` starts api, web, and admin together and points Hyperdrive at Compose. The wrangler + Vite dual-process path is an escape hatch. Details live in [Local development](/docs/local-development).

## Work on zstack itself

```bash
git clone git@github.com:Wania-Labs/zstack.git
cd zstack
pnpm install
pnpm dev:services
pnpm db:migrate && pnpm db:seed
cp apps/api/.dev.vars.example apps/api/.dev.vars
pnpm alchemy:dev
```

Docs for the authoring site:

```bash
cd docs
pnpm install
pnpm dev
```

Docs run on http://localhost:4000 with a separate lockfile.
