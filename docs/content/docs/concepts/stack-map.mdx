## Request path

```text
Browser (web or admin)
  → same-origin /api/*
  → apps/api Hono Worker
  → oRPC + Zod contracts  |  Better Auth
  → Effect use cases
  → ports (EmailService, AiService, Database, …)
  ← adapters (console / Bento / fake / gateway / Drizzle)
  ← Alchemy bindings (Hyperdrive, secrets, Workers)
```

Frontends import `@zstack/contracts`, `@zstack/i18n`, and `@zstack/analytics` only. They do not import `apps/api` source.

## Apps

| Path         | Package         | Role                                                            |
| ------------ | --------------- | --------------------------------------------------------------- |
| `apps/api`   | `@zstack/api`   | Hono Worker: auth, oRPC, Effect services, DB, queues, workflows |
| `apps/web`   | `@zstack/web`   | Customer TanStack Start shell                                   |
| `apps/admin` | `@zstack/admin` | Staff TanStack Start shell (`staff.me` gate)                    |

## Packages

| Path                   | Package               | Role                                             |
| ---------------------- | --------------------- | ------------------------------------------------ |
| `packages/contracts`   | `@zstack/contracts`   | Zod + oRPC contracts (client-safe)               |
| `packages/analytics`   | `@zstack/analytics`   | Typed product events; PostHog Capture when keyed |
| `packages/auth-access` | `@zstack/auth-access` | Shared Better Auth admin role AC                 |
| `packages/email`       | `@zstack/email`       | React Email templates                            |
| `packages/i18n`        | `@zstack/i18n`        | Paraglide catalogs and runtime                   |

## Infrastructure

Alchemy (`alchemy.run.ts` + `infra/*`) owns Cloudflare resources and deploy. `product.config.ts` declares capability intent. Never put secrets there.

Local Postgres is Compose (`compose.yaml`). Deploy uses PlanetScale Postgres through Hyperdrive.

## Inside the API

| Area      | Path                      | Role                                                                                                                |
| --------- | ------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| HTTP edge | `apps/api/src/http/`      | Session, mount auth/oRPC/health/objects                                                                             |
| Modules   | `apps/api/src/modules/`   | Product verticals (auth, ai, staff, health, billing)                                                                |
| Platform  | `apps/api/src/platform/`  | Ports and adapters (email, ai, db, billing, analytics, object store, flags, queue, workflow, observability, effect) |
| Queues    | `apps/api/src/queues/`    | `JOBS` consumer on this Worker                                                                                      |
| Workflows | `apps/api/src/workflows/` | Cloudflare Workflow classes on this Worker                                                                          |
