Product code asks for **capability IDs** (`chat.fast`, `chat.smart`, `extract.structured`). Model strings live only in `apps/api/src/platform/ai/`.

## Defaults

- Empty `AI_GATEWAY_API_KEY` → deterministic **fake** models (no spend)
- Key bound → Vercel AI Gateway via `@ai-sdk/gateway`
- oRPC: `ai.capabilities` (public), `ai.complete` (signed-in)

## Evals

`vitest-evals` + `@vitest-evals/harness-ai-sdk` run in product CI with fake models. Live gateway evals are opt-in and never the default gate.
